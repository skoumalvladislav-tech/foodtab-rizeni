   - Database → Extensions: zapnout `pg_cron` a `pg_net`.
   - Project Settings → Data API → Exposed schemas: jen `public` a `graphql_public`.
   - Integrations → Vault, dvě tajemství:
     - `foodtab_app_url` = `https://foodtab-rizeni.vercel.app`;
     - `foodtab_cron_secret` = stejná hodnota jako `CRON_SECRET` ve Vercelu.
     - **Nikdy přes SQL Editor.**
   - SQL Editor: `select * from app.naplanovat_ulohy();` musí vrátit 9 úloh.
   - Za 20 minut: `select * from app.planovac_stav();`. Kód 401 znamená, že heslo ve Vaultu nesedí s Vercelem.
   - Pokud už je to hotové a pokladna se přesto nesynchronizuje každou hodinu, pošlete mi výsledek `app.planovac_stav()`. Do databáze ani do logů Vercelu se odsud nedostanu.
